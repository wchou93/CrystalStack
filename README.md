# CrystalStack

**CrystalStack** builds the five classical interlayer stacking arrangements of a
2D covalent organic framework (COF) from a single-layer CIF, through a small
Flask web application. Upload one or more monolayers, pick the stacking modes,
and download ready-to-view CIF files of the resulting bilayers.

## What it does

| Mode | Construction |
|------|--------------|
| **eclipsed (AA)** | second layer directly above the first, zero in-plane offset |
| **inclined** | second layer shifted laterally and lowered; the crystallographic *c* axis becomes tilted |
| **serrated (AA&prime;)** | *c* doubled; layers alternate between AA and AA&prime; positions |
| **staggered (AB)** | *c* doubled; second layer placed on the pore site of the layer below |
| **rotated** | second layer generated by a symmetry operation (transpose by default, 60&deg;–300&deg; rotations and mirrors also offered), not by a translation |

Key properties:

- **CIF in, CIF out.** Input is a P1 CIF of a single layer; every output is
  written as a standard P1 CIF that opens directly in common crystallographic
  viewers.
- **Automatic offset selection.** For hexagonal and square lattices the
  staggered mode places the upper layer on the pore centre of the lower one;
  the serrated mode applies the AA&prime; glide known from the reference
  systems. Every generated offset reports its provenance
  (`matched reference`, `rule`, `manual`, ...).
- **Manual override.** Fractional or Cartesian offsets can be entered by hand;
  the inclined mode then derives the tilted *c* axis and the tilt angle from
  the given projection.
- **Batch processing.** Several CIF files can be uploaded at once; all of
  them are processed with the same parameters and the results are bundled
  into one ZIP, organised in one folder per input file.
- **Monolayer extraction.** A multilayer input can additionally be exported
  as its first sheet alone (`monolayer.cif`), with the *c* axis reset to a
  single layer, ready to be stacked again.
- **Symmetry transparency.** Symmetry operations listed in a CIF are expanded
  automatically and the expansion is reported (`42 sites x 8 operations ->
  336 atoms`). A file that *declares* a space group but lists no operations
  is rejected with an explanation instead of being silently read as its
  asymmetric unit; 1D chains and molecular (non-layered) inputs are rejected
  with a clear message as well.
- **Rotated mode is validated, never silent.** Before a rotation / mirror
  stacking is built, the operation is checked against the layer (a PBC
  residual test) and applied about the nearest symmetry axis — the axes of a
  2D net need not sit at the origin. An operation that is no symmetry
  operation of the layer at all produces a loud warning and an
  `unvalidated` provenance flag. A staggered offset that maps atoms exactly
  onto atoms (node-on-node, typical of non-primitive cells) is diagnosed the
  same way.
- **Validated.** Offsets and cell parameters reproduce DFT-relaxed reference
  structures collected in `reference/` (see below); the regression suite
  checks them numerically.

## Quick start

### Windows (one-click)

Double-click `run_webapp.bat`. It detects a suitable Python (3.10+), creates a
local `.venv`, installs the dependencies and starts the server; the browser
opens automatically.

### Any platform

```bash
python -m venv .venv
# activate the virtual environment, then:
pip install -r requirements.txt
python app.py
```

Then open <http://127.0.0.1:5000> in a browser (a free port is used if 5000
is taken).

## Usage

1. **Upload** one or more CIFs, each containing one layer (see `examples/`).
2. **Choose** the stacking modes and adjust parameters if needed
   (layer gap, in-plane offset); for multilayer inputs an extracted
   `monolayer.cif` can be requested as well.
3. **Download** the generated CIF files, individually or bundled as a ZIP.

## Examples

`examples/` ships with ready-to-run inputs:

| File | Content |
|------|---------|
| `COF-1_monolayer.cif` | COF-1 monolayer, hexagonal |
| `COF-5_monolayer.cif` | COF-5 monolayer, hexagonal |
| `CTF-1_monolayer.cif` | CTF-1 monolayer, hexagonal |
| `Pc-PBBA_monolayer.cif` | Pc-PBBA monolayer, square |
| `CuPc_monolayer.cif` | first layer extracted from the rotated reference bilayer; run the rotated mode on it to regenerate that bilayer |

## Reference data

`reference/` contains the CIF files used to validate the construction rules
(eclipsed, inclined, serrated and staggered arrangements of COF-1, COF-5,
CTF-1 and Pc-PBBA, plus the rotated reference). These are the structures the
regression tests compare against.

## Repository layout

```
crystalstack/
├── app.py                 Flask application (UI, upload, run management)
├── layer_stacking.py      core stacking engine
├── stacking_rules.py      automatic offset selection and provenance
├── cif_io.py              CIF reader/writer (P1, symmetry expansion)
├── benchmark_scaling.py   timing benchmark
├── test_layer_stacking.py regression suite (135 checks)
├── smoke_test_web.py      end-to-end web smoke test
├── run_webapp.bat         Windows one-click launcher
├── requirements.txt
├── templates/  static/    web interface
├── reference/             DFT reference structures (CIF)
└── examples/              sample monolayer inputs (CIF)
```

## Requirements
